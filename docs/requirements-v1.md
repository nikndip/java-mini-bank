# Требования к программе «Мини-банк»

Версия 1
Дата 22.11.2026

## Назначение и границы

Учебная консольная программа позволяет пользователю пополнять счета,
переводить средства между ними, просматривать баланс и историю операций.
Используются два вымышленных счёта A и B.
Данные хранятся в памяти только в течение одного запуска.
Регистрация, авторизация, кредиты, проценты и работа с реальными
банковскими счетами находятся вне объёма этой версии.

## Требования

R01. Программа находится в src/MiniBank.java без объявления package.
Она компилируется и запускается на Java 17, использует только стандартную
библиотеку. Объём исходников программы — 50–150 строк без пустых строк
и строк только с комментариями. Проверочный код хранится отдельно.

R02. При каждом запуске существуют ровно два счёта — A и B.
Начальный баланс каждого равен 0 копеек, история пуста.
Балансы хранятся как long в целых копейках.
Допустимый баланс — от 0 до 1000000000 копеек включительно.

R03. Программа читает команды построчно из стандартного ввода.
Допустимы следующие формы:
balance <счёт>
deposit <счёт> <сумма>
transfer <отправитель> <получатель> <сумма>
history
exit

Названия команд чувствительны к регистру и пишутся строчными буквами.
Пробелы и табуляции по краям строки игнорируются, между аргументами
допускается несколько пробелов или табуляций.
Неизвестная команда, неверное количество аргументов или пустая строка
дают одну строку ERR_COMMAND. После ошибки чтение команд продолжается.

R04. Допустимые идентификаторы счетов — только A и B.
Другой идентификатор в команде balance, deposit или transfer
даёт одну строку ERR_ACCOUNT.

R05. Сумма операции задаётся последовательностью цифр ASCII 0–9.
Её числовое значение должно быть от 1 до 1000000000 включительно.
Начальные нули разрешены.
Знак, дробная часть, экспоненциальная запись, другие символы
и значение вне диапазона дают одну строку ERR_AMOUNT.

R06. Команда balance выводит одну строку:
BALANCE <счёт> <баланс>
Баланс выражается в копейках. Например, для нового счёта A:
BALANCE A 0

R07. Успешная команда deposit увеличивает баланс указанного счёта
на сумму и выводит:
OK DEPOSIT <счёт> <сумма>

Если новый баланс превысил бы 1000000000 копеек,
операция отклоняется с сообщением ERR_LIMIT.
Сумма в успешном сообщении выводится без начальных нулей.

R08. Успешная команда transfer уменьшает баланс отправителя
и увеличивает баланс получателя на одну и ту же сумму.
Выводится:
OK TRANSFER <отправитель> <получатель> <сумма>

Если средств отправителя недостаточно, выводится ERR_FUNDS.
Если баланс получателя превысил бы 1000000000 копеек,
выводится ERR_LIMIT.
Сумма в успешном сообщении выводится без начальных нулей.

R09. Перевод со счёта на тот же счёт отклоняется.
Для корректной по формату суммы и существующего счёта выводится:
ERR_SAME_ACCOUNT

R10. В общую историю добавляются только успешные пополнения и переводы.
Команда history выводит записи в порядке выполнения операций:
DEPOSIT <счёт> <сумма>
TRANSFER <отправитель> <получатель> <сумма>

Каждая запись занимает отдельную строку.
Суммы записываются без начальных нулей.
Для пустой истории выводится одна строка EMPTY.
Просмотр истории не изменяет её содержимое.

R11. При нескольких нарушениях выводится только первая применимая ошибка
в следующем порядке:
ERR_COMMAND
ERR_ACCOUNT
ERR_AMOUNT
ERR_SAME_ACCOUNT
ERR_FUNDS
ERR_LIMIT

Проверяются только условия, относящиеся к выбранной команде.
При любой отклонённой операции оба баланса и история сохраняются
в состоянии до этой операции.

R12. Команда exit выводит одну строку BYE и завершает программу.
Последующие строки ввода игнорируются.
Конец входного потока также завершает программу, без дополнительного
сообщения. Программа не выводит меню, приглашения ко вводу или
отладочные сообщения. Все предусмотренные сообщения завершаются
переводом строки.
